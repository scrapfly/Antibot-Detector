看看任何網站是如何防範機器人的。Scrapfly 反機器人偵測器會顯示每個網頁用了哪些反機器人系統、CAPTCHA 和指紋辨識技術，每項符合結果有多確定，以及繞過它們有多難。免費使用。

您會看到什麼
• 工具列圖示上的數字：網頁用了多少項防護。
• 每項防護對應一張卡片，顯示它的信賴度、難度，以及暴露它的訊號：URL、Cookie、標頭、網頁程式碼、網頁元素、瀏覽器 API 呼叫和要求內文。
• 內建 70 個偵測器：30 個反機器人系統、19 種 CAPTCHA 和 21 種指紋辨識技術。每個都是純 JSON 檔案，您可以閱讀、編輯或擴充。

彈出式視窗裡有什麼
• 偵測：目前網頁用了什麼，以及每項符合結果背後的證據。
• 歷史記錄：掃描過的每個網頁都能搜尋。您可以釘選網頁、新增備註，查看網站的防護何時變更，依篩選條件匯出（JSON、CSV 或文字），還能自動備份。
• 規則：啟用或停用偵測器，不必等新版本就能更新，還可以編輯其中的模式、撰寫自己的規則。
• 進階：為受支援的防護提供依需求使用的工具，例如提取網站金鑰、檢查 Cookie 和分析指令碼。
• 設定：快取、略過的網域、通知、Webhook、分享連結、顏色和 22 種介面語言。
• 歷史記錄統計資料（設定 → 資料 → 開啟統計資料）：根據您的歷史記錄在裝置上計算的私人圖表，例如最常遇到的系統和最難的網站。

適用對象
想在動手寫程式碼之前先弄清楚網頁有什麼防護的網頁爬蟲開發人員，資安研究人員，以及想了解自家機器人防護從外部看起來如何的網站擁有者。

隱私
偵測完全在您的瀏覽器中執行。沒有帳號，也沒有分析追蹤，您造訪的網頁永遠不會傳送給 Scrapfly。擴充功能只會發出少量您看得到的要求：來自本專案公開 GitHub 發行版本的偵測器更新、網站圖示（網站自己的圖示；網站沒有時，使用 Google 的 favicon 服務）、語言旗幟圖示，以及傳送到您自己的 Webhook 或分享連結的要求（只有在您開啟後才會發出）。選用的歷史記錄自動備份會儲存到您的「下載」資料夾。

語言
介面提供 22 種語言，包括西班牙文、法文、德文、葡萄牙文、俄文、日文、韓文、中文、阿拉伯文和印地文。

開放原始碼
程式碼和所有偵測器都在 GitHub（scrapfly/Antibot-Detector）上開放原始碼：可以在那裡回報問題或新增偵測器。
