어떤 웹사이트든 봇을 어떻게 막고 있는지 확인해 보세요. Scrapfly 안티봇 탐지기는 각 페이지가 사용하는 안티봇 시스템, CAPTCHA, 핑거프린팅 기술을 탐지별 신뢰도, 우회 난이도와 함께 보여 줍니다. 무료로 사용할 수 있습니다.

표시되는 정보
• 도구 모음 아이콘에 표시되는 숫자는 해당 페이지가 사용하는 보호 기능의 개수입니다.
• 보호 기능마다 카드가 표시되며, 신뢰도와 난이도, 그리고 탐지의 단서가 된 신호(URL, 쿠키, 헤더, 페이지 코드, 페이지 요소, 브라우저 API 호출, 요청 본문)를 확인할 수 있습니다.
• 탐지기 70종 포함: 안티봇 시스템 30종, CAPTCHA 19종, 핑거프린팅 기술 21종. 모두 직접 읽고 수정하고 확장할 수 있는 단순한 JSON 파일입니다.

팝업 구성
• 탐지: 현재 페이지가 사용하는 항목을 각 탐지 결과의 근거와 함께 보여 줍니다.
• 기록: 스캔한 모든 페이지를 검색할 수 있습니다. 페이지를 고정하고 메모를 추가하며, 사이트의 보호 기능이 언제 바뀌었는지도 확인할 수 있습니다. 필터를 적용한 내보내기(JSON, CSV, 텍스트)와 자동 백업도 지원합니다.
• 규칙: 탐지기를 켜거나 끄고, 새 버전을 기다리지 않고 업데이트하고, 패턴을 편집하고, 나만의 규칙을 작성할 수 있습니다.
• 고급: 지원되는 보호 기능을 대상으로 필요할 때 실행하는 도구입니다. 사이트 키 추출, 쿠키 확인, 스크립트 분석 등을 할 수 있습니다.
• 설정: 캐시, 도메인 건너뛰기, 알림, 웹훅, 공유 링크, 색상, 22개 인터페이스 언어.
• 기록 통계(설정 → 데이터 → 통계 열기): 기록을 바탕으로 내 기기에서 계산하는 비공개 차트입니다. 가장 자주 마주치는 보호 시스템, 가장 까다로운 사이트 등을 볼 수 있습니다.

이런 분들을 위해
코드를 작성하기 전에 페이지가 무엇으로 보호되고 있는지 알고 싶은 웹 스크래핑 개발자, 보안 연구원, 그리고 자사의 봇 방어가 외부에서 어떻게 보이는지 점검하려는 사이트 운영자를 위한 도구입니다.

개인정보 보호
탐지는 전적으로 브라우저 안에서 이루어집니다. 계정도 애널리틱스도 없으며, 방문한 페이지가 Scrapfly로 전송되는 일은 없습니다. 이 확장 프로그램이 보내는 요청은 확인할 수 있는 몇 가지뿐입니다. 이 프로젝트의 공개 GitHub 릴리스에서 받는 탐지기 업데이트, 사이트 아이콘(사이트 자체 아이콘, 없는 경우 Google 파비콘 서비스), 언어별 국기, 그리고 사용자가 켠 경우에 한해 본인의 웹훅 또는 공유 링크입니다. 선택 사항인 기록 자동 백업은 다운로드 폴더에 저장됩니다.

언어
인터페이스는 22개 언어로 제공되며, 스페인어, 프랑스어, 독일어, 포르투갈어, 러시아어, 일본어, 한국어, 중국어, 아랍어, 힌디어 등이 포함됩니다.

오픈소스
코드와 모든 탐지기는 GitHub(scrapfly/Antibot-Detector)에 오픈소스로 공개되어 있습니다. 그곳에서 문제를 제보하거나 탐지기를 추가할 수 있습니다.
