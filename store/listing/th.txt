ดูว่าเว็บไซต์ใดก็ตามป้องกันตัวเองจากบอตอย่างไร Scrapfly ตัวตรวจจับ anti-bot แสดงให้เห็นว่าแต่ละหน้าใช้ระบบ anti-bot, CAPTCHA และเทคนิค fingerprinting อะไรบ้าง ความมั่นใจของแต่ละรายการที่ตรงกันอยู่ที่เท่าไร และข้ามผ่านได้ยากเพียงใด ใช้งานได้ฟรี

สิ่งที่คุณจะเห็น
• ตัวเลขบนไอคอนในแถบเครื่องมือ: จำนวนระบบป้องกันที่หน้านั้นใช้
• การ์ดสำหรับระบบป้องกันแต่ละระบบ แสดงความมั่นใจ ความยาก และสัญญาณที่ทำให้ตรวจพบ ได้แก่ URL คุกกี้ เฮดเดอร์ โค้ดของหน้า องค์ประกอบบนหน้า การเรียก API ของเบราว์เซอร์ และเนื้อหาของคำขอ
• มาพร้อมตัวตรวจจับ 70 ตัว: ระบบ anti-bot 30 ระบบ, CAPTCHA 19 แบบ และเทคนิค fingerprinting 21 แบบ ตัวตรวจจับแต่ละตัวเป็นไฟล์ JSON ธรรมดาที่คุณอ่าน แก้ไข หรือต่อยอดได้

ภายในป็อปอัป
• การตรวจจับ: สิ่งที่หน้าปัจจุบันใช้ พร้อมหลักฐานเบื้องหลังแต่ละรายการที่ตรงกัน
• ประวัติ: เก็บทุกหน้าที่สแกนไว้ให้ค้นหาได้ ปักหมุดหน้า เพิ่มโน้ต ดูว่าระบบป้องกันของไซต์เปลี่ยนเมื่อใด ส่งออกพร้อมตัวกรอง (JSON, CSV หรือข้อความ) และสำรองข้อมูลอัตโนมัติ
• กฎ: เปิดหรือปิดตัวตรวจจับ อัปเดตโดยไม่ต้องรอเวอร์ชันใหม่ แก้ไขรูปแบบ และเขียนกฎของคุณเอง
• ขั้นสูง: เครื่องมือสำหรับระบบป้องกันที่รองรับ เปิดใช้เมื่อต้องการ เช่น ดึง Site Key ตรวจสอบคุกกี้ และวิเคราะห์สคริปต์
• การตั้งค่า: แคช โดเมนที่ข้าม การแจ้งเตือน Webhook ลิงก์แชร์ สี และภาษาของส่วนขยาย 22 ภาษา
• สถิติประวัติ (การตั้งค่า → ข้อมูล → เปิดสถิติ): แผนภูมิส่วนตัวที่คำนวณบนอุปกรณ์ของคุณจากประวัติ เช่น ระบบที่คุณพบบ่อยที่สุดและไซต์ที่ข้ามผ่านยากที่สุด

สร้างมาเพื่อ
นักพัฒนา web scraping ที่อยากรู้ว่าอะไรปกป้องหน้าเว็บอยู่ก่อนเขียนโค้ดใด ๆ นักวิจัยด้านความปลอดภัย และเจ้าของไซต์ที่ต้องการตรวจดูว่าระบบป้องกันบอตของตนดูเป็นอย่างไรเมื่อมองจากภายนอก

ความเป็นส่วนตัว
การตรวจจับทำงานทั้งหมดในเบราว์เซอร์ของคุณ ไม่มีบัญชีผู้ใช้ ไม่มีระบบวิเคราะห์การใช้งาน และหน้าที่คุณเข้าชมจะไม่ถูกส่งไปยัง Scrapfly เลย ส่วนขยายส่งคำขอเพียงไม่กี่รายการที่คุณดูได้เอง ได้แก่ การอัปเดตตัวตรวจจับจากรีลีส GitHub สาธารณะของโปรเจกต์นี้ ไอคอนไซต์ (ของไซต์เอง หรือบริการ favicon ของ Google เมื่อไซต์ไม่มี) ธงภาษา และ webhook หรือลิงก์แชร์ของคุณเอง ซึ่งจะส่งเฉพาะเมื่อคุณเปิดใช้เท่านั้น การสำรองข้อมูลประวัติอัตโนมัติ (ไม่บังคับ) จะบันทึกลงในโฟลเดอร์ดาวน์โหลดของคุณ

ภาษา
ส่วนขยายมีให้เลือกใช้ 22 ภาษา รวมถึงภาษาสเปน ฝรั่งเศส เยอรมัน โปรตุเกส รัสเซีย ญี่ปุ่น เกาหลี จีน อาหรับ และฮินดี
