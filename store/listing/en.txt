See how any website defends itself against bots. Scrapfly Anti-bot Detector shows which anti-bot systems, CAPTCHAs and fingerprinting techniques each page uses, how sure each match is and how hard it is to get past. Free to use.

What you see
• A number on the toolbar icon: how many protections the page uses.
• One card per protection with its confidence, its difficulty and the signals that gave it away: URLs, cookies, headers, page code, page elements, browser API calls and request bodies.
• 70 detectors included: 30 anti-bot systems, 19 CAPTCHAs and 21 fingerprinting techniques. Each one is a plain JSON file you can read, edit or extend.

Inside the popup
• Detection: what the current page uses, with the evidence behind each match.
• History: every scanned page, searchable. Pin pages, add notes, see when a site's protections change, export with filters (JSON, CSV or text) and back up automatically.
• Rules: switch detectors on or off, update them without waiting for a new version, edit patterns and write your own rules.
• Advanced: on-demand tools for supported protections, such as extracting site keys, checking cookies and analyzing scripts.
• Settings: caching, sites to skip, notifications, webhooks, share links, colors and 22 interface languages.
• Statistics (from Settings → Data): private charts computed on your device from your history, such as the systems you meet most and the hardest sites.

Made for
Web scraping developers who want to know what protects a page before writing any code, security researchers, and site owners checking how their bot defenses look from the outside.

Privacy
Detection runs entirely in your browser. There are no accounts and no analytics, and the pages you visit are never sent to Scrapfly. The extension only makes a few requests you can see: detector updates from this project's public GitHub releases, site icons (a site's own, or Google's favicon service when a site has none), language flags and, only if you turn them on, your own webhook or share link. Optional automatic history backups are saved to your Downloads folder.

Languages
The interface is available in 22 languages, including Spanish, French, German, Portuguese, Russian, Japanese, Korean, Chinese, Arabic and Hindi.

Open source
The code and every detector are open source on GitHub (scrapfly/Antibot-Detector): report a problem or add a detector there.
