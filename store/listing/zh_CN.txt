看看任何网站是如何防范机器人的。Scrapfly 反机器人检测器会显示每个页面用了哪些反机器人系统、验证码和指纹识别技术，每项匹配有多大把握，以及绕过它们有多难。免费使用。

你会看到什么
• 工具栏图标上的数字：页面用了多少项防护。
• 每项防护对应一张卡片，显示它的置信度、难度，以及暴露它的信号：URL、Cookie、请求头、页面代码、页面元素、浏览器 API 调用和请求正文。
• 内置 70 个检测器：30 个反机器人系统、19 种验证码和 21 种指纹识别技术。每个都是普通的 JSON 文件，你可以阅读、编辑或扩展。

弹窗里有什么
• 检测：当前页面用了什么，以及每项匹配背后的证据。
• 历史记录：扫描过的每个页面都能搜索。你可以固定页面、添加备注，了解网站的防护何时发生变化，按筛选条件导出（JSON、CSV 或文本），还能自动备份。
• 规则：启用或停用检测器，无需等待新版本就能更新，还可以编辑其中的模式、编写自己的规则。
• 高级：为受支持的防护提供按需使用的工具，例如提取站点密钥、检查 Cookie 和分析脚本。
• 设置：缓存、跳过的域名、通知、Webhook、分享链接、颜色和 22 种界面语言。
• 历史统计（设置 → 数据 → 打开统计）：根据你的历史记录在设备上计算出的私密图表，例如最常遇到的系统和最难的网站。

适用人群
想在动手写代码之前先弄清页面有什么防护的网页抓取开发者，安全研究人员，以及想从外部看看自家机器人防护是什么样子的网站所有者。

隐私
检测完全在你的浏览器中运行。没有账号，也没有统计分析，你访问的页面永远不会发送给 Scrapfly。扩展只发出少量你能看到的请求：来自本项目公开 GitHub 发布版本的检测器更新、网站图标（网站自己的图标；网站没有时，用 Google 的 favicon 服务）、语言旗帜图标，以及发往你自己的 Webhook 或分享链接的请求（仅在你开启后才会发出）。可选的历史记录自动备份会保存到你的“下载”文件夹。

语言
界面提供 22 种语言，包括西班牙语、法语、德语、葡萄牙语、俄语、日语、韩语、中文、阿拉伯语和印地语。

开源
代码和所有检测器都在 GitHub（scrapfly/Antibot-Detector）上开源：可以在那里反馈问题或添加检测器。
