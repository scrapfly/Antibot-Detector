あらゆるウェブサイトが、ボットからどう身を守っているのかを確認できます。Scrapfly アンチボット検出器は、各ページが使っているアンチボットシステム、CAPTCHA、フィンガープリント技術を、検出ごとの信頼度と回避の難易度とともに表示します。無料で使えます。

表示される内容
• ツールバーのアイコンに表示される数字は、そのページが使っている保護機能の数です。
• 保護機能ごとにカードが表示され、信頼度、難易度、そして検出の手がかりとなった痕跡（URL、Cookie、ヘッダー、ページのコード、ページ上の要素、ブラウザ API の呼び出し、リクエスト本文）を確認できます。
• 検出器を70種類収録（アンチボットシステム30種、CAPTCHA 19種、フィンガープリント技術21種）。どれもシンプルな JSON ファイルで、読むのも、編集するのも、拡張するのも自由です。

ポップアップの中身
• 検出: 現在のページが使っているものを、検出ごとの根拠とともに表示します。
• 履歴: スキャンしたすべてのページを検索できます。ページをピン留めしたり、メモを追加したり、サイトの保護機能がいつ変わったかを確認したりできます。フィルターを使ったエクスポート（JSON、CSV、テキスト）や、自動バックアップにも対応しています。
• ルール: 検出器のオン・オフを切り替え、新バージョンを待たずに更新し、パターンを編集し、独自のルールを書けます。
• 詳細: 対応している保護機能向けに、必要なときに使えるツールを用意しています。サイトキーの抽出、Cookie の確認、スクリプトの解析などができます。
• 設定: キャッシュ、スキップするドメイン、通知、Webhook、共有リンク、色、22の表示言語。
• 履歴の統計（設定 → データ → 統計を開く）: 履歴をもとに、お使いのデバイス上で計算されるプライベートなグラフ。最もよく出会う保護システムや、最も難しいサイトなどがわかります。

こんな方のために
コードを書く前に、ページが何で守られているかを知りたいウェブスクレイピングの開発者、セキュリティ研究者、自社のボット対策が外からどう見えるかを確かめたいサイト運営者に向けたツールです。

プライバシー
検出はすべてブラウザ内で実行されます。アカウントもアナリティクスもなく、閲覧したページが Scrapfly に送信されることはありません。この拡張機能が行うリクエストは、次のいくつかだけで、いずれも確認できます。このプロジェクトの公開 GitHub リリースから取得する検出器の更新、サイトのアイコン（そのサイト自身のアイコン、ない場合は Google のファビコンサービス）、言語ごとの国旗アイコン、そして、オンにした場合に限り、ご自身の Webhook または共有リンクです。履歴の自動バックアップ（任意）は、「ダウンロード」フォルダに保存されます。

言語
画面の表示は22言語に対応しており、スペイン語、フランス語、ドイツ語、ポルトガル語、ロシア語、日本語、韓国語、中国語、アラビア語、ヒンディー語などが含まれます。

オープンソース
コードも、すべての検出器も、GitHub（scrapfly/Antibot-Detector）でオープンソースとして公開されています。そちらで問題を報告したり、検出器を追加したりできます。
