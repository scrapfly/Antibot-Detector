Detection Configuration

Available Events:
onScrapflyReady Extension loaded and initialized
onScrapflyDetection Detection completed with results
onScrapflyError Detection error occurred
Usage Example: 
window.addEventListener('onScrapflyDetection', (e) => {
  console.log('Detections:', e.detail.detections);
  console.log('URL:', e.detail.url);
});
Available variables: <SITEURL>, <HOSTNAME>, <TIMESTAMP>, <DETECTION_COUNT>, <CATEGORIES>
Example: https://api.example.com/webhook?url=<SITEURL>&count=<DETECTION_COUNT>&time=<TIMESTAMP>

History Configuration

How it works:

When enabled, the extension will prevent duplicate history entries for the same URL within the specified time window.

  • Full URL: Blocks duplicates with exact same URL (including query parameters)
  • Domain: Blocks duplicates from the same domain (e.g., example.com/page1 and example.com/page2 are considered the same)
  • Path: Blocks duplicates with same domain and path, ignoring query parameters (e.g., example.com/page?id=1 and example.com/page?id=2 are considered the same)

Example: If you set 1 hour with "Full URL" scope, visiting the same page twice within 1 hour will only create one history entry.
