# F5 BIG-IP ASM のボット対策: 検出方法とスクレイピングへの影響

F5 BIG-IP ASM は、一部のウェブサイトがページの手前に置くボット対策（アンチボット）または不正利用対策のレイヤーです。F5 BIG-IP ASM の回避方法を調べている場合も、サイトで F5 BIG-IP ASM を検出したい場合も、F5 BIG-IP ASM によるスクレイピングのブロックを調査している場合も、最初にやることは同じです。リクエストに応答しているのが本当に F5 BIG-IP ASM かどうかを確認することです。このページでは、Scrapfly Antibot Detector 拡張機能が F5 BIG-IP ASM のボット検出を見分けるために使う 6 件の公開シグナルと、それぞれがどの程度 F5 BIG-IP ASM を示唆するか、そして自動化クライアントにとってそれが通常何を意味するかをまとめています。

## 概要

F5 BIG-IP Application Security Manager (ASM) は F5 のウェブアプリケーションファイアウォールです。通常はサイト自身のインフラチームが運用し、ボット防御機能を含むことがあります。

公式サイト: [https://www.f5.com/](https://www.f5.com/)

## サイトが F5 BIG-IP ASM を使っているかを見分ける方法

これらのシグナルは、`detect-f5` に対する拡張機能自身の検出ルール（ルールのバージョン 2.3.0、最終更新日 2026-10-26）から生成されています。シグナルはあくまで目安です。信頼度とは、そのシグナル単体が確認されたときに拡張機能がどの程度確信を持つかを表します。「補強のみ」とマークされたシグナルは、他の製品でも発生しうるため、それだけでは判定に加算されません。

### Cookie

ページに設定される Cookie の名前（値が照合される場合は値も）。単純な単語でない限り、パターンは正規表現です。

| シグナル | 信頼度 | 示唆する内容 |
| --- | --- | --- |
| `^TS01[0-9a-f]{6,8}(?:_[0-9]+)?$ = ^01[0-9a-f]{40,}$` | 100% | BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value |
| `^TS[0-9a-f]{8}(?:_[0-9]+)?$` | 20% (補強のみ) | Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names) |
| `^TSPD_101(?:_[A-Za-z0-9]{1,16})?$` | 70% | BIG-IP ASM client-side challenge cookie (TSPD_101 default prefix, e.g. TSPD_101_DID) |
| `^BIGipServer[A-Za-z0-9_.~-]+$` | 40% (補強のみ) | BIG-IP LTM persistence cookie (load balancer, not WAF) |
| `^f5avr[0-9a-z_]+$` | 30% (補強のみ) | BIG-IP AVR analytics cookie |

### ページとスクリプトの内容

ページまたはそのスクリプト内で見つかるテキスト。

| シグナル | 信頼度 | 示唆する内容 |
| --- | --- | --- |
| `Your support ID is:? ?[0-9]{15,20}` | 30% (補強のみ) | BIG-IP ASM block page support ID |

### 組み合わせ

一部のシグナルは、単独よりも組み合わさったときに高く評価されます。拡張機能はこれらの組み合わせも報告します。

| 組み合わせ | 信頼度 | 必要な条件 |
| --- | --- | --- |
| ASM cookie behind a BIG-IP load balancer | 85% | (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value または Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)) および BIG-IP LTM persistence cookie (load balancer, not WAF) |
| ASM block page | 100% | BIG-IP ASM block page support ID および BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value |
| ASM cookie with BIG-IP analytics | 80% | (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value または Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)) および BIG-IP AVR analytics cookie |
| ASM block page with a legacy or load-balancer cookie | 95% | BIG-IP ASM block page support ID および (Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names) または BIG-IP LTM persistence cookie (load balancer, not WAF)) |
| ASM cookie with its client-side challenge cookie | 95% | BIG-IP ASM client-side challenge cookie (TSPD_101 default prefix, e.g. TSPD_101_DID) および (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value または Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)) |

## 難易度

**中.** 「中」は、拡張機能がこの対策を実際の障害と評価していることを意味します。ブラウザ、リクエストの詳細、またはその両方に対するチェックが行われ、それらは時間とともに変化すると考えてください。

この評価は拡張機能独自の経験則であり、ベンダーの見解ではありません。また、サイトの設定によって、同じ製品でも突破しやすくも難しくもなります。

## スクレイピングへの影響

F5 BIG-IP ASM が存在する場合、本物で一貫性のあるブラウザセッションに見えないリクエストは、チャレンジを要求されたり、遅延させられたり、拒否されたりすることがあり、欲しかったコンテンツの代わりにチャレンジページやブロックページが返されることがあります。実際にどうなるかは、サイト運営者が製品をどう設定したかによって決まり、サイトごとに異なり、予告なく変わることもあります。検出結果は、ブロックされる保証ではなく、実際に受け取るレスポンスを確認すべき理由として扱ってください。

F5 BIG-IP ASM で保護されたページを、回避策を自分で維持することなくスクレイピングするには、Scrapfly の [Anti Scraping Protection のドキュメント](https://scrapfly.io/docs/scrape-api/anti-scraping-protection) と [Scrape API](https://scrapfly.io/docs/scrape-api/getting-started) をご覧ください。スクレイピングは許可されている範囲に限り、サイトの利用規約と robots のルールを尊重してください。

## 拡張機能で検出する

Chrome 用の無料の [Scrapfly Anti-bot Detector](https://chromewebstore.google.com/detail/scrapfly-anti-bot-detecto/pdpakdgmjhkfimgaihlgaaiijlbilkca) をインストールしてページを開くと、ポップアップに F5 BIG-IP ASM が、信頼度、難易度、一致したシグナルの詳細とともに表示されます。詳しくは [プロジェクトの README](../../README.ja.md) をご覧いただくか、[拡張機能が検出するすべてのアンチボット対策](README.md) をご覧ください。
