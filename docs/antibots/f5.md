# F5 BIG-IP ASM bot protection: how to detect it (and what it means for scraping)

F5 BIG-IP ASM is a bot protection or anti-abuse layer that some websites put in front of their pages. If you are looking for a F5 BIG-IP ASM bypass, trying to detect F5 BIG-IP ASM on a site, or investigating web scraping blocked by F5 BIG-IP ASM, the first step is the same: confirm that F5 BIG-IP ASM is really what answers your requests. This page lists the 6 public signals that the Scrapfly Antibot Detector extension uses to recognise F5 BIG-IP ASM bot detection, how strongly each one points to it, and what that usually means for an automated client.

## What it is

F5 BIG-IP Application Security Manager (ASM) is F5's web application firewall. It is usually run by a site's own infrastructure team and can include bot defence features.

Official site: [https://www.f5.com/](https://www.f5.com/)

## How to tell a site uses F5 BIG-IP ASM

These signals are generated from the extension's own detection rules for `detect-f5` (rule version 2.3.0, last updated 2026-10-26). A signal is only an indication: confidence is how sure the extension is when that one signal is seen. Signals marked "corroboration only" never count on their own, because other products can produce them too.

### Cookies

Cookie names (and values, where one is matched) set on the page. Patterns are regular expressions unless they are plain words.

| Signal | Confidence | What it indicates |
| --- | --- | --- |
| `^TS01[0-9a-f]{6,8}(?:_[0-9]+)?$ = ^01[0-9a-f]{40,}$` | 100% | BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value |
| `^TS[0-9a-f]{8}(?:_[0-9]+)?$` | 20% (corroboration only) | Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names) |
| `^TSPD_101(?:_[A-Za-z0-9]{1,16})?$` | 70% | BIG-IP ASM client-side challenge cookie (TSPD_101 default prefix, e.g. TSPD_101_DID) |
| `^BIGipServer[A-Za-z0-9_.~-]+$` | 40% (corroboration only) | BIG-IP LTM persistence cookie (load balancer, not WAF) |
| `^f5avr[0-9a-z_]+$` | 30% (corroboration only) | BIG-IP AVR analytics cookie |

### Page and script content

Text found inside the page or its scripts.

| Signal | Confidence | What it indicates |
| --- | --- | --- |
| `Your support ID is:? ?[0-9]{15,20}` | 30% (corroboration only) | BIG-IP ASM block page support ID |

### Combinations

Some signals score higher together than alone. These combinations are what the extension also reports.

| Combination | Confidence | Needs |
| --- | --- | --- |
| ASM cookie behind a BIG-IP load balancer | 85% | (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value or Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)) and BIG-IP LTM persistence cookie (load balancer, not WAF) |
| ASM block page | 100% | BIG-IP ASM block page support ID and BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value |
| ASM cookie with BIG-IP analytics | 80% | (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value or Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)) and BIG-IP AVR analytics cookie |
| ASM block page with a legacy or load-balancer cookie | 95% | BIG-IP ASM block page support ID and (Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names) or BIG-IP LTM persistence cookie (load balancer, not WAF)) |
| ASM cookie with its client-side challenge cookie | 95% | BIG-IP ASM client-side challenge cookie (TSPD_101 default prefix, e.g. TSPD_101_DID) and (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value or Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)) |

## Difficulty

**Medium.** Medium means the extension rates this protection as a real obstacle: expect checks on the browser, on request details, or on both, and expect them to change over time.

The rating is the extension's own rule of thumb, not a statement by the vendor, and a site's configuration can make the same product easier or harder.

## What it means for scraping

If F5 BIG-IP ASM is present, a request that does not look like a real, consistent browser session may be challenged, delayed or refused, and the response can be a challenge or block page instead of the content you wanted. What exactly happens depends on how the site owner configured the product, which can differ from one site to the next and can change without notice. Treat a detection as a reason to look at the response you actually receive, not as a guarantee of a block.

To scrape pages protected by F5 BIG-IP ASM without maintaining the workarounds yourself, see Scrapfly's [Anti Scraping Protection documentation](https://scrapfly.io/docs/scrape-api/anti-scraping-protection) and the [Scrape API](https://scrapfly.io/docs/scrape-api/getting-started). Only scrape what you are allowed to, and respect the site's terms and robots rules.
