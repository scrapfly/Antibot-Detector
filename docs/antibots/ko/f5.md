# F5 BIG-IP ASM 봇 차단: 감지 방법과 웹 스크래핑에 미치는 영향

F5 BIG-IP ASM은(는) 일부 웹사이트가 페이지 앞단에 두는 봇 차단 또는 어뷰징 방지 계층입니다. F5 BIG-IP ASM 우회 방법을 찾고 있거나, 사이트에서 F5 BIG-IP ASM을(를) 감지하려 하거나, F5 BIG-IP ASM이(가) 막는 웹 스크래핑을 조사하는 경우에도 첫 단계는 같습니다. 요청에 실제로 응답하는 것이 F5 BIG-IP ASM인지 확인하는 것입니다. 이 페이지는 Scrapfly Antibot Detector 확장 프로그램이 F5 BIG-IP ASM 봇 탐지를 식별하는 데 쓰는 공개 신호 6개와 각 신호가 얼마나 강하게 F5 BIG-IP ASM을(를) 가리키는지, 그리고 자동화 클라이언트에 대체로 어떤 의미인지를 정리합니다.

## 개요

F5 BIG-IP Application Security Manager(ASM)는 F5의 웹 애플리케이션 방화벽입니다. 보통 사이트 자체 인프라 팀이 운영하며 봇 방어 기능이 포함될 수 있습니다.

공식 사이트: [https://www.f5.com/](https://www.f5.com/)

## 사이트가 F5 BIG-IP ASM을(를) 사용하는지 확인하는 방법

이 신호들은 `detect-f5`에 대한 확장 프로그램의 자체 탐지 규칙(규칙 버전 2.4.0, 최종 업데이트 2026-11-12)에서 생성되었습니다. 신호는 어디까지나 정황일 뿐이며, 신뢰도는 해당 신호 하나가 관찰되었을 때 확장 프로그램이 얼마나 확신하는지를 나타냅니다. "보조 근거로만 사용"으로 표시된 신호는 다른 제품도 만들어 낼 수 있으므로 단독으로는 집계되지 않습니다.

### 쿠키

페이지에서 설정된 쿠키 이름(값이 일치 대상인 경우 값 포함)입니다. 일반 단어가 아닌 한 패턴은 정규식입니다.

| 신호 | 신뢰도 | 의미 |
| --- | --- | --- |
| `^TS01[0-9a-f]{6,8}(?:_[0-9]+)?$ = ^01[0-9a-f]{40,}$` | 100% | BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value |
| `^TS[0-9a-f]{8}(?:_[0-9]+)?$` | 20% (보조 근거로만 사용) | Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names) |
| `^TSPD_101(?:_[A-Za-z0-9]{1,16})?$` | 70% | BIG-IP ASM client-side challenge cookie (TSPD_101 default prefix, e.g. TSPD_101_DID) |
| `^BIGipServer[A-Za-z0-9_.~-]+$` | 40% (보조 근거로만 사용) | BIG-IP LTM persistence cookie (load balancer, not WAF) |
| `^f5avr[0-9a-z_]+$` | 30% (보조 근거로만 사용) | BIG-IP AVR analytics cookie |

### 페이지 및 스크립트 콘텐츠

페이지 또는 페이지의 스크립트 안에서 발견되는 텍스트입니다.

| 신호 | 신뢰도 | 의미 |
| --- | --- | --- |
| `Your support ID is:? ?[0-9]{15,20}` | 30% (보조 근거로만 사용) | BIG-IP ASM block page support ID |

### 조합

일부 신호는 함께 나타날 때 단독일 때보다 점수가 높습니다. 확장 프로그램은 이러한 조합도 함께 보고합니다.

| 조합 | 신뢰도 | 필요 조건 |
| --- | --- | --- |
| ASM cookie behind a BIG-IP load balancer | 85% | (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value 또는 Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)) 그리고 BIG-IP LTM persistence cookie (load balancer, not WAF) |
| ASM block page | 100% | BIG-IP ASM block page support ID 그리고 BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value |
| ASM cookie with BIG-IP analytics | 80% | (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value 또는 Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)) 그리고 BIG-IP AVR analytics cookie |
| ASM block page with a legacy or load-balancer cookie | 95% | BIG-IP ASM block page support ID 그리고 (Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names) 또는 BIG-IP LTM persistence cookie (load balancer, not WAF)) |
| ASM cookie with its client-side challenge cookie | 95% | BIG-IP ASM client-side challenge cookie (TSPD_101 default prefix, e.g. TSPD_101_DID) 그리고 (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value 또는 Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)) |

## 난이도

이 등급은 확장 프로그램 자체의 경험칙이며 공급업체의 공식 입장이 아닙니다. 사이트의 설정에 따라 같은 제품이라도 더 쉽거나 더 어려울 수 있습니다.

## 웹 스크래핑에 미치는 영향

F5 BIG-IP ASM이(가) 있으면 실제 브라우저 세션처럼 일관되게 보이지 않는 요청은 챌린지를 받거나, 지연되거나, 거부될 수 있으며, 원하던 콘텐츠 대신 챌린지 또는 차단 페이지가 응답으로 올 수 있습니다. 정확히 어떤 일이 일어나는지는 사이트 운영자가 제품을 어떻게 설정했는지에 달려 있으며, 이는 사이트마다 다를 수 있고 예고 없이 바뀔 수도 있습니다. 탐지 결과는 실제로 받는 응답을 확인해 보라는 신호로 받아들이고, 차단이 보장된다는 뜻으로 받아들이지 마세요.

F5 BIG-IP ASM이(가) 보호하는 페이지를 우회 방법을 직접 유지하지 않고 스크래핑하려면 Scrapfly의 [Anti Scraping Protection 문서](https://scrapfly.io/docs/scrape-api/anti-scraping-protection)와(과) [Scrape API](https://scrapfly.io/docs/scrape-api/getting-started)를 참고하세요. 허용된 범위 안에서만 스크래핑하고, 사이트의 이용 약관과 robots 규칙을 존중하세요.
