# F5 BIG-IP ASM 反爬防护：如何检测网站是否使用它（以及它对网页抓取意味着什么）

F5 BIG-IP ASM 是一些网站放在页面前面的反爬虫（反机器人）或反滥用防护层。无论你是在寻找 F5 BIG-IP ASM 绕过方法、想检测某个网站是否使用了 F5 BIG-IP ASM，还是在排查网页抓取被 F5 BIG-IP ASM 拦截的问题，第一步都是一样的：确认响应你请求的确实是 F5 BIG-IP ASM。本页列出 Scrapfly Antibot Detector 扩展用来识别 F5 BIG-IP ASM 机器人检测的 6 个公开特征，说明每个特征指向它的可信程度，以及这通常对自动化客户端意味着什么。

## 它是什么

F5 BIG-IP Application Security Manager (ASM) 是 F5 的 Web 应用防火墙。它通常由网站自己的基础设施团队运行，并可能包含机器人防御功能。

官方网站: [https://www.f5.com/](https://www.f5.com/)

## 如何判断网站使用了 F5 BIG-IP ASM

这些特征由扩展自身针对 `detect-f5` 的检测规则生成（规则版本 2.3.0，最后更新于 2026-10-26）。单个特征只是一种迹象：置信度表示扩展在看到该特征时有多大把握。标记为“仅作佐证”的特征本身不计入判断，因为其他产品也可能产生它们。

### Cookie

页面上设置的 Cookie 名称（匹配到值时也包括值）。除非是普通单词，否则匹配模式均为正则表达式。

| 特征 | 置信度 | 含义 |
| --- | --- | --- |
| `^TS01[0-9a-f]{6,8}(?:_[0-9]+)?$ = ^01[0-9a-f]{40,}$` | 100% | BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value |
| `^TS[0-9a-f]{8}(?:_[0-9]+)?$` | 20% (仅作佐证) | Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names) |
| `^TSPD_101(?:_[A-Za-z0-9]{1,16})?$` | 70% | BIG-IP ASM client-side challenge cookie (TSPD_101 default prefix, e.g. TSPD_101_DID) |
| `^BIGipServer[A-Za-z0-9_.~-]+$` | 40% (仅作佐证) | BIG-IP LTM persistence cookie (load balancer, not WAF) |
| `^f5avr[0-9a-z_]+$` | 30% (仅作佐证) | BIG-IP AVR analytics cookie |

### 页面和脚本内容

在页面或其脚本中发现的文本。

| 特征 | 置信度 | 含义 |
| --- | --- | --- |
| `Your support ID is:? ?[0-9]{15,20}` | 30% (仅作佐证) | BIG-IP ASM block page support ID |

### 组合特征

有些特征组合在一起的得分比单独出现时更高。扩展也会报告这些组合。

| 组合 | 置信度 | 条件 |
| --- | --- | --- |
| ASM cookie behind a BIG-IP load balancer | 85% | (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value或Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names))和BIG-IP LTM persistence cookie (load balancer, not WAF) |
| ASM block page | 100% | BIG-IP ASM block page support ID和BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value |
| ASM cookie with BIG-IP analytics | 80% | (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value或Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names))和BIG-IP AVR analytics cookie |
| ASM block page with a legacy or load-balancer cookie | 95% | BIG-IP ASM block page support ID和(Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)或BIG-IP LTM persistence cookie (load balancer, not WAF)) |
| ASM cookie with its client-side challenge cookie | 95% | BIG-IP ASM client-side challenge cookie (TSPD_101 default prefix, e.g. TSPD_101_DID)和(BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value或Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)) |

## 难度

**中.** 中表示扩展将这种防护评为真正的障碍：预计会检查浏览器、请求细节或两者，并且这些检查会随时间变化。

该评级是扩展自身的经验判断，并非厂商的说法，而且网站的配置可能让同一款产品变得更容易或更难应对。

## 对网页抓取意味着什么

如果存在 F5 BIG-IP ASM，不像真实、一致的浏览器会话的请求可能会被质询、延迟或拒绝，返回的响应也可能是质询页或拦截页，而不是你想要的内容。具体会发生什么取决于网站所有者如何配置该产品，不同网站可能各不相同，并且可能在不另行通知的情况下改变。请把检测结果当作查看你实际收到的响应的理由，而不是一定会被拦截的保证。

如果想抓取受 F5 BIG-IP ASM 保护的页面而不必自己维护各种应对方案，请参阅 Scrapfly 的 [反抓取防护（Anti Scraping Protection）文档](https://scrapfly.io/docs/scrape-api/anti-scraping-protection) 和 [Scrape API](https://scrapfly.io/docs/scrape-api/getting-started)。请只抓取你有权抓取的内容，并遵守网站的服务条款和 robots 规则。
