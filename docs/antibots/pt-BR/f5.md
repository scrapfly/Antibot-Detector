# Proteção antibot F5 BIG-IP ASM: como detectar (e o que ela significa para o web scraping)

F5 BIG-IP ASM é uma camada de proteção contra bots ou contra abuso que alguns sites colocam na frente de suas páginas. Se você procura como contornar o F5 BIG-IP ASM, quer detectar o F5 BIG-IP ASM em um site ou está investigando um web scraping bloqueado pelo F5 BIG-IP ASM, o primeiro passo é o mesmo: confirmar que é mesmo o F5 BIG-IP ASM que responde às suas requisições. Esta página lista os 6 sinais públicos que a extensão Scrapfly Antibot Detector usa para reconhecer a detecção de bots do F5 BIG-IP ASM, o quanto cada um aponta para ele e o que isso costuma significar para um cliente automatizado.

## O que é

O F5 BIG-IP Application Security Manager (ASM) é o firewall de aplicações web da F5. Costuma ser operado pela equipe de infraestrutura do próprio site e pode incluir recursos de defesa contra bots.

Site oficial: [https://www.f5.com/](https://www.f5.com/)

## Como saber se um site usa F5 BIG-IP ASM

Estes sinais são gerados a partir das regras de detecção da própria extensão para `detect-f5` (versão da regra 2.3.0, última atualização 2026-10-26). Um sinal é apenas um indício: a confiança indica o quanto a extensão tem certeza quando vê aquele sinal isolado. Os sinais marcados como "apenas corroboração" nunca contam por si sós, porque outros produtos também podem produzi-los.

### Cookies

Nomes de cookies (e valores, quando algum é comparado) definidos na página. Os padrões são expressões regulares, a menos que sejam palavras simples.

| Sinal | Confiança | O que indica |
| --- | --- | --- |
| `^TS01[0-9a-f]{6,8}(?:_[0-9]+)?$ = ^01[0-9a-f]{40,}$` | 100% | BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value |
| `^TS[0-9a-f]{8}(?:_[0-9]+)?$` | 20% (apenas corroboração) | Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names) |
| `^TSPD_101(?:_[A-Za-z0-9]{1,16})?$` | 70% | BIG-IP ASM client-side challenge cookie (TSPD_101 default prefix, e.g. TSPD_101_DID) |
| `^BIGipServer[A-Za-z0-9_.~-]+$` | 40% (apenas corroboração) | BIG-IP LTM persistence cookie (load balancer, not WAF) |
| `^f5avr[0-9a-z_]+$` | 30% (apenas corroboração) | BIG-IP AVR analytics cookie |

### Conteúdo da página e dos scripts

Texto encontrado dentro da página ou de seus scripts.

| Sinal | Confiança | O que indica |
| --- | --- | --- |
| `Your support ID is:? ?[0-9]{15,20}` | 30% (apenas corroboração) | BIG-IP ASM block page support ID |

### Combinações

Alguns sinais pontuam mais juntos do que sozinhos. A extensão também relata essas combinações.

| Combinação | Confiança | Requer |
| --- | --- | --- |
| ASM cookie behind a BIG-IP load balancer | 85% | (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value ou Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)) e BIG-IP LTM persistence cookie (load balancer, not WAF) |
| ASM block page | 100% | BIG-IP ASM block page support ID e BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value |
| ASM cookie with BIG-IP analytics | 80% | (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value ou Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)) e BIG-IP AVR analytics cookie |
| ASM block page with a legacy or load-balancer cookie | 95% | BIG-IP ASM block page support ID e (Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names) ou BIG-IP LTM persistence cookie (load balancer, not WAF)) |
| ASM cookie with its client-side challenge cookie | 95% | BIG-IP ASM client-side challenge cookie (TSPD_101 default prefix, e.g. TSPD_101_DID) e (BIG-IP ASM session cookie (TS01xxxxxx) with its 01-prefixed value ou Older BIG-IP ASM TSxxxxxxxx cookie name (also matches TS01 names)) |

## Dificuldade

**Média.** Média significa que a extensão avalia essa proteção como um obstáculo real: espere verificações no navegador, nos detalhes da requisição ou em ambos, e espere que elas mudem com o tempo.

A classificação é uma regra prática da própria extensão, não uma declaração do fornecedor, e a configuração de um site pode tornar o mesmo produto mais fácil ou mais difícil de contornar.

## O que significa para o scraping

Se o F5 BIG-IP ASM estiver presente, uma requisição que não pareça uma sessão de navegador real e consistente pode ser desafiada, atrasada ou recusada, e a resposta pode ser uma página de desafio ou de bloqueio em vez do conteúdo que você queria. O que exatamente acontece depende de como o responsável pelo site configurou o produto, o que pode variar de um site para outro e mudar sem aviso. Trate uma detecção como um motivo para examinar a resposta que você realmente recebe, não como garantia de bloqueio.

Para fazer scraping de páginas protegidas pelo F5 BIG-IP ASM sem precisar manter você mesmo as soluções de contorno, veja a [documentação do Anti Scraping Protection](https://scrapfly.io/docs/scrape-api/anti-scraping-protection) e a [Scrape API](https://scrapfly.io/docs/scrape-api/getting-started) da Scrapfly. Faça scraping apenas do que você tem permissão para acessar e respeite os termos do site e as regras de robots.
